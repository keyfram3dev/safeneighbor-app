# Home Roadmap 3.0

This document tracks the next Home improvements after the earlier IA, dashboard, personalization, live-context, and polish passes were completed.

## Goal

Push Home from a strong adaptive launcher into a calmer, smarter, and more situational command center.

The focus for 3.0 is:
- better live awareness and report context
- smarter featured-card rotation
- richer returning-user personalization
- more refined mobile pacing
- stronger desktop composition
- longer-term retention and re-entry support

## Phase 1: Better Live Awareness

Goal:
- make Community Reports feel more spatially and temporally meaningful on Home

Changes:
- improve nearby-activity summaries
- better distinguish:
  - no activity
  - recent activity
  - clustered activity
  - nearby activity
- optionally add clearer nearest-distance or “in your area” language when useful

Success criteria:
- users can tell quickly whether Home is reacting to meaningful real-time community activity

## Phase 2: Smarter Featured-Card Rotation

Goal:
- make the most prominent Home cards change based on context instead of staying static

Changes:
- rotate featured emphasis based on:
  - live nearby reports
  - incomplete setup
  - recently used tools
  - rights refresh needs
- keep the system simple and predictable

Success criteria:
- featured content feels chosen for the moment, not generic

## Phase 3: Richer Returning-User Personalization

Goal:
- make repeat users feel like Home remembers and supports their habits

Changes:
- strengthen recent-action and continue behavior
- surface stronger “most used” or “recently used” patterns when appropriate
- reduce setup-focused emphasis for users who are already ready

Success criteria:
- returning users get to likely next actions faster

## Phase 4: Mobile-First Pacing Polish

Goal:
- make the first screen of Home even faster to understand on phones

Changes:
- tighten spacing between top modules
- reduce visual competition in the first scroll
- improve how recommendation, live activity, and quick actions stack on small screens

Success criteria:
- the first useful action is easier to reach and scan on mobile

## Phase 5: Desktop Composition Refinement

Goal:
- make Home feel more editorial and less grid-like on wide screens

Changes:
- refine section widths and breakpoints
- introduce stronger asymmetry where helpful
- make the hero and first sections feel more composed on large displays

Success criteria:
- desktop feels intentionally designed rather than simply expanded

## Phase 6: Retention And Re-entry

Goal:
- make Home more useful over time, not just on first setup

Changes:
- add gentle refresh prompts for rights, family plan, or trusted contacts when stale
- improve quiet-state support for prepared users
- optionally add lightweight reminders or “keep ready” nudges

Success criteria:
- Home continues to feel useful after setup is complete

## Recommended Build Order

1. Better Live Awareness
2. Smarter Featured-Card Rotation
3. Richer Returning-User Personalization
4. Mobile-First Pacing Polish
5. Desktop Composition Refinement
6. Retention And Re-entry

## Best Next Step

If continuing soon, start with:
- better live-awareness for nearby and clustered reports
- then featured-card rotation tied to live activity and recent use
