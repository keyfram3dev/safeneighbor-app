# Home Roadmap Next

This document tracks the next round of Home screen improvements after the initial information architecture, accessibility, live context, setup dashboard, recommendation logic, and mobile pacing passes were completed.

## Status

Completed in previous Home work:
- information architecture regrouping
- hero and section-header redesign
- featured vs standard card hierarchy
- desktop layout improvements
- lower-page cleanup
- Community Reports emphasis
- interactive hero shortcut cards
- setup dashboard and checklist
- live community activity summary
- continue/resume card
- smarter recommendations
- first-time vs returning-user behavior
- lightweight location-aware prioritization
- trust/proof strip
- mobile quick-action and pacing fixes

Remaining work in this roadmap is optional enhancement work, not missing baseline functionality.

## Phase 1: Home Intelligence

Goal:
- make Home feel more aware of what is happening right now, especially around Community Reports

Potential work:
- improve nearby-report messaging with stronger tiers like quiet, recent activity, active cluster
- show more precise context when useful, such as nearest distance band or clustering language
- distinguish between nearby activity and general map activity more clearly
- optionally surface saved-area awareness if the app already has that state available

Success criteria:
- users can tell whether Home is reacting to meaningful live activity
- Community Reports feels like a live signal, not just another card

## Phase 2: Home Personalization

Goal:
- make Home feel more tailored to the user’s actual state and history

Potential work:
- change featured-card emphasis based on preparedness, nearby activity, or recent use
- adapt the top recommendation block more aggressively for prepared vs unprepared users
- make returning users see faster-entry operational actions
- make first-time users see more setup and orientation guidance
- optionally add a lightweight “best next action for you” mode instead of static featured ordering

Success criteria:
- new and returning users feel like they are seeing different, intentional versions of Home
- featured content feels chosen, not generic

## Phase 3: Home Dashboard Maturity

Goal:
- make the setup area feel more like a readiness dashboard than a checklist bundle

Potential work:
- add clearer “all set” presentation when core setup is complete
- add friendlier progress language and stronger completion states
- optionally surface refresh/reminder states when setup is complete but may be stale
- give the continue/resume area more dashboard-like weight
- tighten how setup, continue, and recommendation relate to each other

Success criteria:
- the top of Home feels like a calm command center
- readiness is easy to scan in one glance

## Phase 4: Home Content Refinement

Goal:
- make the page read faster and feel more editorially polished

Potential work:
- tighten hero and section copy again after real usage review
- shorten support copy where it still feels dense
- improve fallback copy for quiet/no-activity states
- unify tone between urgent, reassuring, and educational messaging
- make section transitions feel more natural

Success criteria:
- Home feels calmer and easier to scan
- copy sounds like one coherent product voice

## Phase 5: Visual Polish Round 2

Goal:
- move Home from strong structure to premium finish

Potential work:
- refine desktop composition on very wide screens
- make featured cards more visually distinct without adding clutter
- polish surface layering, gradients, and accent control
- improve card rhythm and spacing between major blocks
- optionally add very subtle motion or richer hover states if they support clarity

Success criteria:
- Home feels more premium and deliberate
- visual hierarchy is strong without feeling busy

## Phase 6: Retention And Re-entry

Goal:
- make Home better for repeat use over time

Potential work:
- add occasional preparedness nudges when setup is complete
- surface refresh prompts like rights review or family-plan review after time passes
- strengthen resume metadata when a user comes back after a gap
- optionally add a “recently used” or “keep sharp” area if it stays lightweight

Success criteria:
- Home remains useful after the first setup
- repeat users feel supported instead of seeing a static landing page

## Recommended Build Order

1. Phase 1: Home Intelligence
2. Phase 2: Home Personalization
3. Phase 3: Home Dashboard Maturity
4. Phase 4: Home Content Refinement
5. Phase 5: Visual Polish Round 2
6. Phase 6: Retention And Re-entry

## Best Next Step

If continuing soon, start with:
- stronger live intelligence for nearby and clustered reports
- then adaptive featured-card prioritization

That combination is likely to deliver the biggest UX gain without expanding the app’s architecture too much.
